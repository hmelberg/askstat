# API-kinds (sdmx/dbnomics/worldbank + kanonisk vokabular) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tre protokoll-adaptere (`sdmx`, `dbnomics`, `worldbank`) bak kind()/registeret slik at OECD, ECB, Norges Bank, IMF, Verdensbanken og ~80 DBnomics-kilder kan leses i alle moduser, pluss (fase 2) et kanonisk spørrevokabular (`years/countries/regions/indicators/filters`) som oversettes per kilde.

**Architecture:** Ny ren modul `js/api-kinds.js` (samme kontrakt som js/pxweb.js: ingen nett/DOM, node --test) eier URL-byggere, flatenere og alias-tabellen. data-directives/resolve normaliserer kildenavn→protokoll-kind og henter kind fra registeret; data-loader får én gren per protokoll (delt _bufCache/proxy); eksport og openstat.py speiler logikken med delte fixtures. Spec: `docs/superpowers/specs/2026-07-25-api-kinds-design.md`.

**Tech Stack:** Vanilla JS (IIFE-moduler, node --test), Deno-edge (hent-core.ts), Python (openstat.py, pytest), pandas/R i eksportert kode.

## Global Constraints

- SDMX-fellen (spec §0): parametre kilden ikke garantert forstår sendes ALDRI — oversett verifiserbart eller kast norsk feil.
- Kolonner ut = API-ets egne navn (OBS_VALUE hos SDMX, value hos WB/dbnomics). Ingen omdøping.
- Alle feilmeldinger på norsk, med kildens egen feiltekst der den finnes.
- Ingen bakoverkompat-hensyn (ingen brukere ennå) — erstatt fremfor å frede.
- Ingen eksterne pakker i app eller eksport (dbnomics-py/pandasdmx/rsdmx kun som doc-tips i katalog-quirks).
- Eksisterende stil: norske kommentarer med spec-referanse, IIFE + `global.X`-eksport + `module.exports`.
- Fase 1 pushes (push-alltid) før fase 2 starter.

```js
// js/api-kinds.js — protokoll-adaptere for API-kilder (økt 2026-07-25,
// spec docs/superpowers/specs/2026-07-25-api-kinds-design.md §1):
// sdmx (OECD/ECB/Norges Bank/IMF …), dbnomics (~80 kilder), worldbank.
// Brukeren skriver KILDEN (kind(oecd)) — kindAlias mapper til protokollen.
// Ren modul uten nett/DOM: kjører under node --test. CSV-serialisering
// gjenbrukes fra js/pxweb.js (columnsToCsv) der flatenere trengs.
(function (global) {
  'use strict';

  // Kildenavn → protokoll-kind. Protokollnavnene er gyldige selv (for kilder
  // utenfor registeret); ukjente navn → null (ikke vår kind).
  var ALIAS = { oecd: 'sdmx', ecb: 'sdmx', norgesbank: 'sdmx', imf: 'sdmx',
                sdmx: 'sdmx', dbnomics: 'dbnomics', worldbank: 'worldbank' };
  function kindAlias(name) { return ALIAS[String(name || '').toLowerCase()] || null; }

  // Forsøk 1 for sdmx-datahenting (spec §0: virker hos OECD og NB; labels=id
  // gir rene koder — NBs default er labels=both). CORS-safelistet header.
  var SDMX_ACCEPT = 'application/vnd.sdmx.data+csv;labels=id';

  // ECB 406-er på Accept-veien men tar format=csvdata (spec §0). 404/422 er
  // ekte feil (ukjent flow/nøkkel) — IKKE formatproblem, ingen fallback.
  function sdmxNeedsFallback(status, contentType) {
    if (status === 406) return true;
    if (status >= 400) return false;
    return String(contentType || '').toLowerCase().indexOf('csv') < 0;
  }

  function sdmxFallbackUrl(url) {
    var s = String(url || '');
    var q = s.indexOf('?');
    var base = q >= 0 ? s.slice(0, q) : s;
    var parts = (q >= 0 ? s.slice(q + 1).split('&') : []).filter(function (p) {
      return p && p.split('=')[0].toLowerCase() !== 'format';
    });
    parts.push('format=csvdata');
    return base + '?' + parts.join('&');
  }

  var api = { kindAlias: kindAlias, SDMX_ACCEPT: SDMX_ACCEPT,
              sdmxNeedsFallback: sdmxNeedsFallback, sdmxFallbackUrl: sdmxFallbackUrl };
  global.ApiKinds = api;
  if (typeof module !== 'undefined' && module.exports) module.exports = api;
})(typeof window !== 'undefined' ? window : globalThis);
```

```js
    var s = String(url || '');
    var q = s.indexOf('?');
    var base = q >= 0 ? s.slice(0, q) : s;
    var parts = (q >= 0 ? s.slice(q + 1).split('&') : []).filter(function (p) {

    parts.sort(function (a, b) {

      return fa - fb;
    });
```
