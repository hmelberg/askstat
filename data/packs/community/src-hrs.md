# HRS — Health and Retirement Study

A biennial panel of US adults aged 50+ and their spouses, running since
1992, covering health, wealth, cognition and retirement transitions.
Public files need free registration; restricted files (biomarker,
genetic, geographic) require application.

```yaml
- id: src-hrs
  name: Health and Retirement Study
  provider: NIA + SSA, University of Michigan ISR
  unit: person aged 50+ and spouses, biennial since 1992
  access: "free-registration (public files); application (restricted biomarker/genetic/geographic)"
  recommended_entry_point: "RAND HRS Longitudinal File — pre-cleaned, harmonized across 15+ waves; using raw core files means hand-merging dozens of wave-specific files"
  sister_studies: "ELSA/SHARE/CHARLS/LASI/MHAS/TILDA and others use harmonised instruments — see the europe-surveys and global-surveys packs; Gateway to Global Aging (g2aging.org) harmonizes variable names across all of them"
```

Start from the RAND HRS Longitudinal File rather than the raw core
files — it is pre-cleaned and already harmonized across 15+ waves, saving
the hand-merge of dozens of wave-specific files. For cross-national
ageing comparisons, ELSA/SHARE/CHARLS/LASI/MHAS/TILDA use harmonised
instruments (see the europe-surveys and global-surveys packs); Gateway to
Global Aging (g2aging.org) harmonizes variable names across all of them.
