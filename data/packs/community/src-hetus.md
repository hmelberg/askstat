# Harmonised European Time Use Surveys (HETUS)

True microdata — household, individual, 10-minute diary records. Round 2
covers reference year 2010 across 17 countries including Norway; Round 3
(HETUS 2020) microdata is not expected before 2027. Access requires an
application (Scientific Use Files, recognised research entities).
