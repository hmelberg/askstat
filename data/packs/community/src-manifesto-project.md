# Manifesto Project (MARPOR)

Party-election manifestos, quasi-sentence coded and aggregated to
party-year, covering 50+ countries since 1945, open after free instant
registration.



`list_core_versions`, `get_core_codebook` and `get_core_citation` work
without a key; other endpoints need the free registered API key.
