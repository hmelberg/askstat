# CROS / CIMES country pages

The European Commission's index of national microdata-access rules, one
page per EU/EEA country — the single best starting point for a country's
current portal, tier names and application process when it is not detailed
elsewhere. Open web pages, no application needed to browse the index itself;
the underlying national sources each keep their own access tiers.
