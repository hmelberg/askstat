# IPEDS — Integrated Postsecondary Education Data System

Institution-level (~6,000+ Title IV institutions) US postsecondary data,
NOT student-level. Open access.



There is no official queryable REST API for IPEDS itself — merge records
on UNITID, or query it through the Urban Institute Education Data Portal
instead (id: src-urban-education-data).
