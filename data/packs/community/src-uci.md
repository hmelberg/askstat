# UCI Machine Learning Repository

Classic benchmark datasets used for teaching examples — not a primary
statistical source. Open landing page; a Python package exists for
programmatic access.

```yaml
- id: src-uci
  name: UCI Machine Learning Repository
  landing: https://archive.ics.uci.edu/
  packages: {python: [ucimlrepo]}
  use: "classic benchmark datasets for teaching examples, not primary statistical sources"
```

Use `ucimlrepo` in Python for programmatic fetches rather than scraping the
landing page.
