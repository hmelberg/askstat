# OFLC disclosure data (H-1B LCA, PERM, H-2A, H-2B)

Open individual-case disclosure data for US labour-certified visa
programs — employer, worksite, offered wage and SOC code per case,
FY2008-present.



Field names and schema change across years, employer names are
unstandardised, and an LCA filing is not the same as a PERM filing or an
actual visa issuance — don't conflate the three.
